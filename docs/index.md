最後に出た5が答えです。足し算のボタンがなくても、「次へ」を繰り返すだけで足し算ができました。

この教材では、0から始めて、次の数、そのまた次の数を作ります。これが「ペアノ算術」の出発点です。そこから、負の数や分数も自分で作っていきます。
